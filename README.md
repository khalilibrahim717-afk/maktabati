# مكتبتي | Maktabati

تطبيق ويب تقدمي (PWA) لإدارة مكتبة، بواجهة عربية RTL، ومصمم ليعمل محلياً دون إنترنت على الهاتف مع قابلية إضافة المزامنة متعددة الأجهزة لاحقاً.

## نطاق الإصدار الأول

- واجهة عربية مناسبة للهاتف.
- إضافة الكتب وتعديلها وحذفها والبحث عنها.
- تخزين محلي باستخدام IndexedDB للعمل دون إنترنت.
- تثبيت التطبيق على الهاتف عبر PWA.
- طباعة تقارير/فواتير بتنسيق مناسب لورق A4.
- نقطة انطلاق لإضافة التقاط الصور/الماسح الضوئي ومزامنة الأجهزة في إصدارات لاحقة.

## التشغيل

افتح `index.html` عبر خادم محلي أو استضف المشروع على HTTPS حتى تتوفر خصائص PWA والتخزين المحلي بشكل موثوق.

## ملاحظات مهمة

- بيانات الإصدار الأول محفوظة على الجهاز الحالي فقط.
- المزامنة بين الأجهزة والنسخ الاحتياطي السحابي غير منفذين بعد؛ يجب تصميمهما مع تسجيل دخول ومزامنة آمنة قبل استخدام أكثر من جهاز.
- لا تخزن بيانات شخصية حساسة في هذه النسخة التجريبية.
